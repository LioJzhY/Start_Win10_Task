# Start_Win10_Task

English:

his batch script can launch Windows 10 tasks on Windows 11. Advantages: low performance overhead, lightweight.
This batch script only supports "ZH-CN". Contributions to support more languages are welcome.

Chinese:（简体中文）

该批处理脚本可在 Windows 11 上启动 Windows 10 任务。
优点：性能开销低、轻量小巧。
仅支持 zh-CN（简体中文），欢迎贡献代码以支持更多语言。
